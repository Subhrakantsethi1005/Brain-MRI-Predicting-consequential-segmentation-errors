# BrainRisk presentation

Download [the PowerPoint deck](BrainRisk.pptx). It contains **24 main slides and 3 backup slides**, with editable charts and tables, MRI examples, a real-data demonstration, speaker notes and source links.

Use [the presenter guide](PRESENTER_GUIDE.md) for rehearsal. Allow about 15–20 minutes for the main talk. The demo on slides 18–19 runs offline with `python demo/run_demo.py`.

The deck distinguishes completed training from configured budgets, validation from test performance, reference-based error labels from reference-free QC, and study novelty from reused methods. It includes the negative BraTS result and exploratory status of the conformal extension. No retraining was performed to create the deck.

The deck targets PowerPoint. Its charts use native literal data. Slides were rendered and inspected with Artifact Tool; native Microsoft PowerPoint opening was not checked. The Spaces service failed before saving slides, so this file is the fallback deliverable.
