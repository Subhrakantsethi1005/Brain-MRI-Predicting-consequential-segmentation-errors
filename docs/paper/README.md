# Manuscripts and protocols

The repository contains several stages of the project. Read the [current evidence audit](../EVIDENCE_AUDIT.md) before quoting a historical manuscript.

| Stage | Narrative | Frozen protocol | Evidence |
|---|---|---|---|
| Early MSD feasibility | `paper.tex`, section drafts | `../../configs/preregistration.yaml` | Historical outputs are not all versioned |
| BraTS 2023 consequence study | `optionB_report.md` | `optionB_preregistration.md` | `../../results/brats2023/` |
| LUMIERE longitudinal study | `longitudinal_report.md` | `longitudinal_preregistration.md` | `../../results/lumiere/` |

Frozen protocols retain their original text. The audit records implementation deviations; a protocol file alone does not prove adherence. PDF, Word and Overleaf exports have moved to `../exports/`. `figures/` retains the original evidence figures and MRI examples. Historical showcase trust labels were computed using reference-mask errors and are not learned QC predictions.
