# Documentation guide

Start with [the evidence audit](EVIDENCE_AUDIT.md) and [reproduction](REPRODUCING.md).

- `paper/`: research narratives, frozen protocols, manuscript sources and original figures. Several narratives predate the audit. Frozen protocols are historical records, not proof of adherence.
- `exports/`: existing PDF, Word and Overleaf exports, retained as historical artifacts.
- `research/`: background literature reports and research notes, separate from experimental evidence.
- `presentation/`: presentation and speaker guide.
- `REORGANIZATION.json`: old-to-new file paths.

The root README and evidence audit take precedence over conflicting claims in earlier reports. Study results are in `results/`, while newly generated run artifacts go to ignored `outputs/`.
